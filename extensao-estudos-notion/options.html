⚙️ Configurações do Estudaí

As chaves ficam salvas só neste navegador.

1. Inteligência que gera os resumos

Crie grátis (sem cartão) em aistudio.google.com/apikey → “Create API key”.
Crie em console.anthropic.com → API Keys (pago).

2. Notion (onde as aulas são salvas)

Crie em notion.so/my-integrations → Nova integração (interna) → copie o token. Crie uma página (ex.: “Meus Estudos”), clique em ••• → Conexões → adicione sua integração, e cole o link aqui. Vira a pasta do curso. Cada aula vira uma pasta dentro dela.

3. Transcrição por áudio (opcional)

Só é necessária se a aula não tiver legendas. O modo “legendas” é gratuito.
